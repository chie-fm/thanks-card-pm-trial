CLI での Sub-issue 作成ガイド

GitHub CLI を使って、既存の Issue に子 Issue（Sub-issue）を作成する手順を、初心者向けに詳しく説明します。

準備：対象 Issue の確認

準備 1
リポジトリ内の Issue 一覧を確認
Sub-issue を追加する親 Issue を確認します。GitHub CLI で Issue 一覧を表示してください。
Copilot に「リポジトリの Issue 一覧を表示してください」と指示
& "C:\Program Files\GitHub CLI\gh.exe" issue list --limit 10
💡 何が表示されるか
Issue 番号（#1, #2 など）とタイトルが表示されます。Sub-issue を追加したい親 Issue の番号をメモしてください。

Step 1：子 Issue を作成

Step 1
Copilot に子 Issue 作成を指示
GitHub CLI で新しい Issue を作成します。本文に親 Issue 番号を記載することで、親子関係を確立します。
Copilot に以下を指示してください： 「GitHub CLI で新しい Issue を作成。タイトル：『Sub-task: 環境構築』、本文：『親 Issue: #6』」
& "C:\Program Files\GitHub CLI\gh.exe" issue create --title "Sub-task: 環境構築" --body "親 Issue: #6"
💡 何が起こるか
新しい Issue が作成され、その URL が表示されます。Issue 番号をメモしてください（例：#7）。
確認
Issue が作成されたことを確認
ターミナルに Issue の URL が表示されます。
https://github.com/[owner]/[repo]/issues/7

Step 2：Issue の本文を編集して親子関係を明確にする

Step 2
Copilot に Issue 編集を指示
Issue #7（作成された Sub-issue）の本文をより詳しく編集して、親子関係をより明確にします。
Copilot に以下を指示してください： 「GitHub CLI で Issue #7 の本文を編集。以下の内容に設定：『## 子 Issue 親 Issue: #6 このタスクは Issue #6 のサブタスクです』」
& "C:\Program Files\GitHub CLI\gh.exe" issue edit 7 --body "## 子 Issue 親 Issue: #6 このタスクは Issue #6 のサブタスクです"
💡 何が起こるか
Issue の本文が更新されます。ターミナルに確認メッセージが表示されます。
確認
Sub-issue が作成されたことを確認
GitHub 上で親 Issue #6 にアクセスして、Sub-issue が表示されているか確認してください。
ブラウザで https://github.com/[owner]/[repo]/issues/6 にアクセス
右側のサイドバーに「Sub-tasks」セクションが表示されている
「Sub-task: 環境構築」という Issue が一覧に表示されている
Issue #7 が表示されている

トラブルシューティング

❌ 問題：「gh コマンドが見つからない」というエラー
GitHub CLI がインストールされていない、またはパスが設定されていない可能性があります。
→ PowerShell を再起動するか、以下のコマンドを使用してください： & "C:\Program Files\GitHub CLI\gh.exe" issue create --title "..." --body "..."
❌ 問題：Issue が作成されない
ターミナルにエラーメッセージが表示されていますか？
→ エラーメッセージを Copilot に伝えて、原因を特定してもらってください。
❌ 問題：Sub-issue が親 Issue に表示されない
GitHub がリアルタイムに親子関係を反映していない可能性があります。
→ ページを再度読み込んでください（ブラウザの F5 キーを押す）。
