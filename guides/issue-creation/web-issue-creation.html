WEB 画面での Issue 作成ガイド

GitHub の WEB 画面を使って、Copilot の指示の下で Issue を作成する手順を、初心者向けに詳しく説明します。

準備：事前確認

準備 1
GitHub にログインしているか確認
GitHub の Issue を作成するには、GitHub アカウントにログインしている必要があります。
ブラウザで https://github.com にアクセスして、右上にあなたのアバター画像が表示されていることを確認してください。
💡 Tips
未ログインの場合は「Sign in」ボタンをクリックしてログインしてください。
準備 2
リポジトリ URL を確認
Issue を作成するリポジトリの URL を確認します。
Copilot に「このリポジトリのURLを確認してください」と指示
このリポジトリのURL確認してください
💡 Tips
Copilot が実行するコマンド：git remote -v

Step 1：Issue 作成ページを開く

Step 1
Copilot に Issue 作成ページを開くよう指示
Copilot に以下の指示を出します。これにより Copilot がリポジトリの Issue 作成ページを自動的に開きます。
GitHub の Issue 作成ページ（https://github.com/[owner]/[repo]/issues/new）をブラウザで開いてください
💡 何が起こるか
Copilot がリポジトリの URL を認識して、自動的にブラウザで Issue 作成ページにアクセスします。
確認
ページが開いたことを確認
「Create new issue」というタイトルのページが表示されていますか？
「Add a title」というテキストボックスが見える
「Type your description here…」というテキストエリアが見える
右下に「Create」ボタンが見える

Step 2：タイトルを入力

Step 2
Copilot にタイトル入力を指示
Copilot に「Add a title」欄に Issue のタイトルを入力するよう指示します。
「Add a title」というテキストボックスに「copilot test issue」と入力してください
💡 何が起こるか
Copilot がタイトル欄をクリックして、「copilot test issue」と入力します。
確認
タイトルが入力されたことを確認
「Add a title」欄に「copilot test issue」が表示されていますか？

Step 3：説明を入力

Step 3
Copilot に説明文入力を指示
次に、Issue の説明文をテキストエリアに入力するよう指示します。
「Type your description here…」というテキストエリアに「追加成功しました」と入力してください
💡 何が起こるか
Copilot が説明欄をクリックして、「追加成功しました」と入力します。
確認
説明文が入力されたことを確認
テキストエリアに「追加成功しました」が表示されていますか？

Step 4：Issue を作成

Step 4
Copilot に Create ボタンをクリックするよう指示
タイトルと説明文を入力したら、「Create」ボタンをクリックして Issue を作成します。
右下の「Create」ボタンをクリックして Issue を作成してください
💡 何が起こるか
Copilot が「Create」ボタンをクリックして、Issue が作成されます。
確認
Issue が作成されたことを確認
ページが Issue の詳細ページにリダイレクトされ、作成した Issue が表示されていますか？
タイトルが「copilot test issue」と表示されている
説明文が「追加成功しました」と表示されている
Issue 番号（例：#5）が表示されている

トラブルシューティング

❌ 問題：Issue 作成ページが開かない
GitHub にログインしていない可能性があります。
→ ブラウザで https://github.com にアクセスして、ログインしてから再度指示してください。
❌ 問題：テキストが入力されない
テキストボックスが正しく認識されていない可能性があります。
→ Copilot に「ページを再度開いてから、テキストボックスをクリックして入力してください」と指示してください。
❌ 問題：Create ボタンが見つからない
ページが完全に読み込まれていない可能性があります。
→ ページを下にスクロールして、Create ボタンを探してください。
