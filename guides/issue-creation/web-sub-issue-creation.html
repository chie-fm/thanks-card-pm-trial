WEB 画面での Sub-issue 作成ガイド

GitHub の WEB 画面を使って、既存の Issue に子 Issue（Sub-issue）を作成する手順を、初心者向けに詳しく説明します。

準備：対象 Issue の確認

準備 1
リポジトリ内の Issue 一覧を確認
Sub-issue を追加する親 Issue を確認します。以下のコマンドで現在のリポジトリの Issue 一覧を表示してください。
& "C:\Program Files\GitHub CLI\gh.exe" issue list --limit 10
💡 何が表示されるか
Issue 番号（#1, #2 など）とタイトルが表示されます。Sub-issue を追加したい親 Issue の番号をメモしてください。
準備 2
GitHub にログインしているか確認
GitHub の WEB 画面にログインしている必要があります。
ブラウザで https://github.com にアクセスして、右上にあなたのアバター画像が表示されていることを確認してください。

Step 1：親 Issue のページを開く

Step 1
Copilot に親 Issue のページを開くよう指示
Sub-issue を追加する親 Issue のページを開きます。（例：Issue #6）
GitHub リポジトリの Issue #6 （あるいは対象の Issue 番号）をブラウザで開いてください
💡 何が起こるか
https://github.com/[owner]/[repo]/issues/6 のような URL で Issue の詳細ページが表示されます。

Step 2：Create sub-issue ボタンをクリック

Step 2
Copilot に Create sub-issue ボタンをクリックするよう指示
Issue ページの右側のサイドバーに「Create sub-issue」ボタンがあります。
右側のサイドバーで「Create sub-issue」ボタンをクリックしてください
💡 どこにあるか
右側のサイドバー（Issue の詳細情報がある場所）を下にスクロールすると見つかります。

Step 3：Sub-issue を作成

Step 3
Copilot に Sub-issue 作成フォームを埋めるよう指示
モーダルが開いたら、Sub-issue のタイトルと説明を入力します。
「Title」欄に「Sub-task: 環境構築」と入力、「Body」欄に「このタスクは Issue #6 のサブタスクです」と入力してください
💡 入力内容
タイトルは「Sub-task: 」という接頭詞をつけることで、Sub-issue であることが明確になります。
確認
Create button をクリック
モーダル下の「Create issue」ボタンをクリックして Sub-issue を作成します。
「Create issue」ボタンをクリックしてください
確認
Sub-issue が作成されたことを確認
親 Issue ページの「Relationships」セクションに新しく作成された Sub-issue が表示されます。
右側のサイドバーに「Sub-tasks」セクションが表示されている
「Sub-task: 環境構築」という Issue が一覧に表示されている
新しい Issue 番号（例：#7）が表示されている

トラブルシューティング

❌ 問題：Create sub-issue ボタンが見つからない
ボタンが表示されていない可能性があります。
→ 右側のサイドバーを下にスクロールしてください。または、ページを再度読み込んでみてください。
❌ 問題：モーダルが開かない
ページの読み込みが完全に終わっていない可能性があります。
→ ページを再度読み込んで、もう一度ボタンをクリックしてください。
❌ 問題：Sub-issue が作成されない
タイトルが空になっていないか確認してください。
→ タイトル欄に入力があることを確認して、「Create issue」ボタンをクリックしてください。
