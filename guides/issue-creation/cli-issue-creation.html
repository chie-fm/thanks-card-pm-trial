CLI での Issue 作成ガイド

GitHub CLI をインストールし、コマンドラインを使って Issue を作成する手順を、初心者向けに詳しく説明します。

Step 1：GitHub CLI をインストール

Step 1-1
Copilot に GitHub CLI インストールを指示
GitHub CLI をインストールするために、Copilot に指示します。
Windows 環境で GitHub CLI をインストールしてください
💡 何が起こるか
Copilot が以下のコマンドを実行します：winget install GitHub.cli
Step 1-2
利用規約に同意
インストール中に利用規約への同意を求められます。
Copilot に「利用規約に同意して、インストール を続行してください」と指示
[Y] はい [N] いいえ: Y
💡 何が起こるか
Copilot がターミナルで「Y」と入力して、インストールを進めます。
確認
インストール完了を確認
ターミナルに「インストールが完了しました」というメッセージが表示されていますか？

Step 2：GitHub CLI で GitHub に認証

Step 2-1
Copilot に GitHub CLI の認証を指示
GitHub CLI を使用するには、GitHub アカウントで認証する必要があります。
GitHub CLI で GitHub に認証してください
💡 何が起こるか
Copilot が以下のコマンドを実行します：gh auth login --web
Step 2-2
Git プロトコルを選択
Git 操作に使用するプロトコルを選択します。初心者は HTTPS を選択してください。
Copilot に「HTTPS を選択してください」と指示
> HTTPS
💡 何が起こるか
HTTPS がデフォルトで選択されているので、Enter キーを押すだけで OK です。
Step 2-3
Git 認証確認
「Authenticate Git with your GitHub credentials?」と聞かれます。
Copilot に「Y と入力してください」と指示
? Authenticate Git with your GitHub credentials? (Y/n) Y
Step 2-4
認証方法を選択
認証方法を選択します。初心者は「Login with a web browser」を選択してください。
Copilot に「ウェブブラウザでログインする方法を選択してください」と指示
💡 何が起こるか
ターミナルに一時的なコード（例：6DAE-AD90）が表示されます。
Step 2-5
ブラウザで認証
ターミナルに「Press Enter to open https://github.com/login/device in your browser...」と表示されます。
Copilot に「Enter キーを押してブラウザを開いてください」と指示
💡 何が起こるか
ブラウザが https://github.com/login/device に開きます。ターミナルに表示されたコードをブラウザに入力してください。
確認
認証完了を確認
ターミナルに「✓ Authentication complete」と表示されたら、認証が成功です。

Step 3：GitHub CLI で Issue を作成

Step 3
Copilot に Issue 作成を指示
認証が完了したら、GitHub CLI を使用して Issue を作成します。
GitHub CLI で Issue を作成してください。タイトルは「copilot test issue」、内容は「追加成功しました」
& "C:\Program Files\GitHub CLI\gh.exe" issue create --title "copilot test issue" --body "追加成功しました"
💡 何が起こるか
Copilot が上記のコマンドをターミナルで実行します。Issue が作成されると、その URL が表示されます。
確認
Issue 作成完了を確認
ターミナルに以下のような形式の URL が表示されていますか？
https://github.com/[owner]/[repo]/issues/[number]
💡 何が起こるか
この URL をクリック（またはブラウザにコピー）すれば、作成された Issue を確認できます。

トラブルシューティング

❌ 問題：「gh コマンドが見つからない」というエラー
GitHub CLI がインストールされていない、またはパスが設定されていない可能性があります。
→ PowerShell を再起動するか、以下のコマンドを使用してください： & "C:\Program Files\GitHub CLI\gh.exe" issue create --title "..." --body "..."
❌ 問題：「認証に失敗した」というエラー
GitHub CLI の認証がまだ完了していない可能性があります。
→ Copilot に「gh auth login --web を実行して認証を完了してください」と指示してください。
❌ 問題：Issue が作成されない
ターミナルにエラーメッセージが表示されていますか？
→ エラーメッセージを Copilot に伝えて、原因を特定してもらってください。
