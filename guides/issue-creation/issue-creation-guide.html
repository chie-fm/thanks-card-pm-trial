Copilot で Issue を作成

初心者向けの詳細な手順書。WEB 画面または CLI コマンドで、簡単に Issue を作成できます。

2つの方法を選択

あなたのやり方に合わせて、WEB 画面または CLI コマンドで Issue を作成できます。

🌐

WEB 画面で作成

GitHub の WEB 画面を使ってブラウザから Issue を作成します。直感的で初心者向け。

  • ブラウザで直感的に操作
  • ラベルやマイルストーンを簡単に設定
  • UI が分かりやすい
詳細な手順を見る →
⌨️

CLI コマンドで作成

GitHub CLI を使ってターミナルからコマンドで Issue を作成します。自動化に向いている。

  • スクリプトで自動化できる
  • 複数の Issue を一括作成
  • プログラム開発者向け
詳細な手順を見る →

📌 始める前に確認すること

✓ GitHub アカウントが必要です。まだない場合は https://github.com で作成してください。

✓ リポジトリへのアクセス権が必要です。Issue を作成するリポジトリにアクセス可能であることを確認してください。

✓ Copilotの指示に従うだけで大丈夫です。各手順書では、Copilot にどう指示すれば良いかを詳しく説明しています。

よくある質問

Q. どちらの方法を選べば良い？
初心者の方は「WEB 画面で作成」をお勧めします。UI が分かりやすく、直感的に操作できます。複数の Issue を頻繁に作成する場合は、CLI がおすすめです。
Q. Copilot がない場合は？
このガイドは Copilot の指示機能を前提としています。Copilot がない場合は、手順書に書かれた操作を自分で行ってください。
Q. 途中でエラーが出た場合は？
各手順書の「トラブルシューティング」セクションを確認してください。よくあるエラーと解決方法を記載しています。
Q. Issue を削除したい場合は？
WEB 画面：Issue の詳細ページで「Delete」をクリック。CLI：gh issue delete [番号] --yes を実行。
Q. 複数の Issue を一括作成できる？
はい。特に CLI は複数の Issue 作成に向いています。各手順書の「応用」セクションを参照してください。
Q. Issue にラベルやマイルストーンを付けたい
WEB 画面：作成後、Issue の詳細ページで設定できます。CLI：--label や --milestone オプションで設定可能です。
